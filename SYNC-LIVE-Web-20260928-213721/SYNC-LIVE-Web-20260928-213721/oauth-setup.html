コメント・タイトルの公式連携

この画面で各サービスのアプリIDを保存すると、公式の許可画面へ進めます。許可ボタンはあなたが押してください。 クライアントシークレットとトークンはこのPC内の .env に保存し、画面へ再表示しません。

Twitch

状態を確認中

  1. Twitch Developer Consoleでアプリを登録。
  2. OAuth Redirect URLに を登録。
  3. 発行されたClient IDとClient Secretを下に入力。
Twitchの許可画面へチャンネル説明の追加許可へ

通常の許可: コメント閲覧、配信タイトル変更。チャンネル説明の追加許可では user:edit も要求します。

YouTube

状態を確認中

  1. Google CloudでYouTube Data API v3を有効化。
  2. 認証情報からOAuthクライアント（ウェブアプリ）を作成。
  3. 承認済みリダイレクトURIに を登録。
  4. Client IDとClient Secretを下に入力。
Googleの許可画面へ

タイトル同期と配信開始に使う枠を選択

要求する権限: YouTube配信の閲覧・管理。許可後、現在のライブ配信枠を確認します。

Kick

状態を確認中

  1. Kickの開発者設定でアプリを作成。
  2. Redirect URLに を登録。
  3. Client IDとClient Secretを下に入力。
Kickの許可画面へ

Kick側でユーザー情報（メールアドレスを含む）の閲覧権限が必須として表示されています。連携するときは許可画面の内容を確認してください。ほかにチャンネル閲覧・タイトル変更・コメントイベント購読を要求します。コメント受信には公開HTTPSのWebhook URLも必要です。
