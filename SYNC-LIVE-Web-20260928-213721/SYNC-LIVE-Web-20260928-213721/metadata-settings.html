配信先ごとの情報設定

タイトル、カテゴリー、タグをサービスごとに別々に設定できます。入力して「保存して反映」を押したサービスだけ更新します。

YouTube

YouTube Studioで選択済みの配信枠の情報を更新します。

YouTubeの説明を次回から固定

今の配信枠の説明をこのPCに保存して、SYNC LIVEが今後新しく作る配信枠に使います。既存の配信枠は変更しません。

候補を選ぶと配信枠に設定します。未選択なら現在のカテゴリーを維持します。
合計500文字以内。空欄のままなら現在のタグを維持します。
YouTubeへアップロードすると現在の選択中の配信枠に反映されます。
YouTubeの書き込みは公式APIの利用枠を使います。タイトルなどの更新は通常、読み取り1回と更新1回（合計約51 units）、サムネイル更新は50 unitsです。利用枠超過時はYouTube Studioで手動更新してください。

Twitch

公式 Twitch API で配信タイトル、カテゴリー、チャンネルタグを更新します。

Twitchチャンネル説明

チャンネルプロフィールに常時表示される説明です。今の説明を読み込んで維持するか、編集して公式APIで反映できます。

説明の反映には Twitch の user:edit 許可が必要です。許可を追加するには下のリンクを開き、Twitch画面で許可してください。Twitchチャンネル説明の追加許可へ（user:edit）
候補を選ぶと設定されます。未選択なら現在のカテゴリーを維持します。
最大10個、各25文字以内。Twitchのタグ規則に合う文字を使用してください。
Twitchの公式APIでタイトル、カテゴリー、タグを更新できます。カスタム配信サムネイルの更新欄は公式APIにないため、サムネイルはTwitch側で設定してください。

Kick

公式 Kick API で配信タイトル、カテゴリー、カスタムタグを更新します。

Kickチャンネル説明

Kickの公開APIはチャンネル説明の書き込みに対応していません。今の説明を読み込んで保存・コピーし、Kick側のチャンネル設定に貼り付けられます。

候補を選ぶと設定されます。未選択なら現在のカテゴリーを維持します。
最大10個です。カテゴリー自体の公式カテゴリータグは自動で扱われます。
Kickの公式APIはタイトル・カテゴリー・カスタムタグを更新できます。サムネイルはAPIで任意の画像を指定できないため、Kick側の配信管理画面で設定してください。

YouTubeで利用枠超過が返った場合、非公式APIで制限を回避することはしません。TwitchとKickも、公式APIが認証不足や利用制限を返した場合は画面に理由を表示します。
